MEU COFRINHO — PUBLICAÇÃO GRATUITA

1. Crie uma conta em github.com.
2. Crie um repositório público chamado meu-cofrinho.
3. Envie os arquivos DE DENTRO desta pasta para a raiz do repositório (index.html, app.js, manifest.webmanifest, sw.js e os ícones).
4. Em Settings > Pages, escolha Deploy from a branch, branch main e pasta /(root), e salve.
5. Aguarde a publicação. Seu endereço será https://SEU-USUARIO.github.io/meu-cofrinho/
6. No Safari do iPhone, abra o endereço, toque em Compartilhar > Adicionar à Tela de Início.

AVISO: Os dados ficam no armazenamento local do aparelho, sem conta ou sincronização. Exporte backups regularmente. Não use navegação privada. Não há integração bancária.
